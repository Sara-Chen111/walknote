# 数据源与合规方案：小红书导入 · 地图与步数引擎 · 国内平台接入

> 版本 v0.2 ｜ 2026-10-19 ｜ 状态：方案定稿，v0.1 已按此实现（含高德双引擎）
> 一句话：**小红书数据只走"用户主动导入"；步数计算境内走高德、境外走 OpenRouteService；国内 OTA 只有飞猪 FlyAI 官方对个人开放，美团对个人关闭。**

## 1. 小红书数据的四条路径（结论：只走第 4 条）

| 路径 | 可行性 | 成本 | 结论 |
|---|---|---|---|
| ① 官方开放平台 | ❌ 个人不可行 | — | open.xiaohongshu.com 面向商家与服务商，笔记接口需企业资质；**无面向外部的关键词搜索 API** |
| ② 第三方按量 API（TikHub/极致了等） | ⚠️ 技术可行但灰 | ~$0.01/次 或 ¥0.1/次 | 上游即非官方接口转售；不适合做产品底座，最多一次性取数验证 |
| ③ 自建爬虫 | ❌ 产品化不建议 | 高（签名逆向维护） | 动态签名存活常以天计；**法律风险实锤** |
| ④ **用户主动导入 + AI 解析** | ✅ 个人可做 | ≈0 | **选定**：用户把攻略"分享"给 App，原文只在本机处理、不留存 |

### 1.1 法律红线（为什么不做爬虫底座）

2025 年判决密集落地，裁判规则清晰：**绕过技术保护措施 + 规模化/商业化 = 加重情节**。

| 判例 | 结果 |
|---|---|
| 小红书诉蝉妈妈（蝉小红） | 杭州中院 2025-04 终审：换 ID + IP 轮换绕过防护，**判赔 490 万元**，停止服务并删除数据，产品关停 |
| "接口集合"转售案（上海） | 提供小红书接口调用 294 万次、获利仅 11 万余元，**判赔 110 万元**（不正当竞争） |
| 固乔软件案（福建） | 批量下载视频 + 改 MD5 规避检测构成不正当竞争（批量下载图片/笔记本身未被认定） |

个人自用小规模抓取实践中极少被追究，但违反平台 ToS 且随时可能升级——**作为要商业化的产品，此路不动**。

### 1.2 选定方案的产品设计（已在 v0.1 实现）

```
用户粘贴笔记正文/链接文字、上传攻略截图
  → 本机内存解析（文本模型提取 / 视觉模型读图 OCR——攻略正文大量在图片里）
  → 结构化：景点 + 打卡卡（机位/构图/姿势/时段/文案）+ 置信度
  → 【强制人工确认环节】用户编辑 → 确认进景点池
  → 原文不留存
```

**为什么这是好设计而不只是合规妥协**：它把取数变成了产品叙事——"你收藏的小红书攻略不再是信息坟墓，分享给行记就变成计划本里的一页"。用户本来就收藏了这些笔记，只是从未被结构化。

**已知坑**：① 小红书分享链接需保留 `xsec_token` 参数否则 403，直接抓页面只能拿到 App 下载壳（v0.1 因此只支持"粘贴文字/截图"，链接自动抓取不做）；② 俗称地名（"XX 路口第 3 根柱子"）与地图 POI 匹配率预期 70-85%——用人工确认 + 手动添加兜底；③ 页面结构变化会使任何解析器失效，故不依赖第三方解析库。

## 2. 步数计算（核心差异化的技术底座）

### 2.1 换算标准

| 项 | 取值 | 说明 |
|---|---|---|
| 步幅 | **0.74 m**（成人均值） | 1 万步 ≈ 7.4 km；精细版可用身高 × 0.41（男 0.415/女 0.413） |
| 步行速度 | 1.25 m/s（4.5 km/h） | 用于行程时间推演 |
| 计入范围 | 住宿↔首末站 + 景点↔景点 全程 | 往返住宿的步行最容易被忽略，必须计入 |

### 2.2 距离来源（双引擎，按坐标自动选源）

| 方案 | 配额/价格 | 适用 | 结论 |
|---|---|---|---|
| **高德 Web 服务 API**（境内选定） | 个人认证免费 15 万次/月（步行/公交/距离共享），3 QPS；超额个人可付费 30 元/万次 | 中国大陆，GCJ-02 坐标 | 境内步行距离 + **公交换乘真实数据**（接驳步行距离、乘车时长）；浏览器可直连 |
| **OpenRouteService**（境外选定） | 免费 2000 次/日 | 全球 OSM 路网，WGS-84 | 日本等境外行程；需用户免费注册 Key |
| 直线距离 × 1.25（降级） | 免费零配置 | — | 任一 Key 未配置时自动降级，界面标注「估算值」 |
| Google Routes API | Essentials 10k 次/SKU/月 | 境外最准 | 可选升级，需绑国际信用卡 |
| 百度 / 腾讯位置服务 | 百度 5000 次/日、腾讯 6000 次/日 | 境内 | 均不支持个人付费加量；MCP 不允许浏览器直连（需代理）；作为高德备选 |

选源规则（`geo.js` 的 `pickProvider`）：两端坐标都在中国大陆范围且配置了高德 Key → 高德；否则有 ORS Key → ORS；否则估算。核对链接同理：境内给高德 URI（`uri.amap.com/navigation`，免 Key），境外给 Google Maps（日本公交另给 Yahoo!乗換案内）。

### 2.3 分段交通决策（已在 `planLeg` 实现）

| 交通档次 | 步行上限 | 超限处理 |
|---|---|---|
| 纯步行 | 2.5 km | 仍步行 + 警告"建议拆天或改交通档" |
| 公交地铁 + 步行 | 1.5 km | 换乘：**境内有高德 Key 时取真实换乘数据**（接驳步行距离 + 乘车时长）；否则按含 500 m 接驳、≈15 km/h（含候车换乘）估算 |
| 打车为主 | 0.6 km | 打车：接驳 80 m，行程时间按 ≈24 km/h + 上车 3 分钟估算 |

> 1.5 km 阈值的依据：国内城市核心区 1.5 km 以内（如南京东路→外滩）绝大多数游客选择步行，1.2 km 会把经典步行线误判为乘车。

## 3. 日本公交换乘（v0.1 深链 → v0.2 API）

**关键事实**：Google Directions API 与 Routes API **官方明确不支持日本 transit**（是官方文档里被点名的唯一例外，消费端 Google Maps App 有完整换乘但 API 不给）——不要在这上面浪费工期。

| 服务 | 能力 | 价格 | 备注 |
|---|---|---|---|
| Yahoo!路線情報深链（v0.1 选定） | 跳转查询 | ¥0 | 无需 Key；`transit.yahoo.co.jp/search/result?from=&to=` 按站名/地名均可 |
| **Jorudan 乗換案内 OpenAPI**（v0.2 首选） | 铁路+飞机+巴士+渡轮 | 免费（注册审核） | 月限 3000 次/接口、总 10000 次；只返回 1 条最优路径；需固定 IP + 回链 |
| NAVITIME API | 全国公交 100% 覆盖、门到门、票价 | RapidAPI 免费 500 次/月；有 90 天免费试用 | 产品化后再谈付费合同 |
| 駅すぱあと（Ekispert） | 时刻表/票价 | 免费档仅站名；付费约 1 日元/次 | 备选 |
| ODPT（公共交通开放数据） | 首都圈 GTFS + REST API | 免费注册 | 覆盖以东京圈为主，适合东京单城深耕 |

**v0.1 策略**：不接换乘 API，每段"公交地铁"行程提供两个深链（Yahoo!乗換案内 + Google Maps），用户点开核对——零成本、零配额、且用户本来就要在手机上查。

## 4. 数据源优先级与实施顺序

| 阶段 | 数据能力 | 动作 |
|---|---|---|
| v0.1（已完成） | 用户导入解析（文本+截图）+ **高德（境内）/ORS（境外）双引擎步数** + 高德真实换乘 + 深链核对 | 本机可用，零 Key 可体验（东京 / 上海两套演示） |
| M1（10 月内） | 配置真实 Key 实测步数准确度（偏差 < 20%） | 注册高德（个人认证）+ ORS + 模型 Key |
| v0.2 | 高德 POI 搜索接入采集箱（俗称地名 → 坐标）；飞猪 FlyAI（景点/门票/酒店 + 分佣，需边缘代理）；联盟 CPS 链接 | 注册 FlyAI 控制台；评估是否加 Cloudflare Worker |
| v0.2（海外） | Jorudan 换乘 API（日本）+ 攻略截图批量导入 | 申请 Jorudan 免费 Key |
| v0.3+（视商业化） | 地名词典（Wikivoyage/OSM/Wikidata 免费合规）补全景点介绍与坐标 | 仅事实层数据，规避内容版权 |

**可补充的免费合规数据**（v0.3 备选）：Wikivoyage（CC BY-SA，景点介绍与玩法）、OpenStreetMap Overpass（POI 坐标）、Wikidata（P625 坐标/P18 图片）——只用于事实层（名称/坐标/开放时间），不用其攻略文本。

## 5. 国内平台接入评估（2026-10-19 调研）

### 5.1 地图三家：都开放、都有官方 MCP，选高德

| 维度 | 高德 | 百度 | 腾讯位置服务 |
|---|---|---|---|
| 个人免费额度（路线/距离/编码） | 15 万次/月共享，3 QPS | 各 5,000 次/日 | 各 6,000 次/日，5 QPS |
| POI 搜索（全场瓶颈） | 5,000 次/月 | 100 次/日 | 200 次/日 |
| 个人能否付费加量 | **能**（30 元/万次，唯一） | 不能 | 不能 |
| 官方 MCP Server | 有（16 工具，含"生成专属地图"唤端） | 有（14 工具，含 `map_mark` 行程分享地图） | 有（15 工具，含途经点排序） |
| MCP 浏览器直连（实测 CORS） | **可**（`Access-Control-Allow-Origin: *`） | 不可 | 不可 |
| 商用门槛 | 技术服务许可 5 万/年起（乘风计划初创免费 1 年） | 技术服务授权 5 万/年起，仅限公司 | 商务报价，仅限企业 |

**选高德的理由**：唯一允许浏览器直连 MCP（契合零后端 BYOK）、唯一允许个人付费加量、公交换乘策略最全（跨城、地铁优先、最多 10 方案）。坐标系：高德/腾讯 GCJ-02，百度 BD-09，不可混用。

**POI 搜索是三家共同的瓶颈**（高德 5,000/月）：v0.2 接入采集箱时必须做本地缓存 + 节流，只用于"俗称地名 → 坐标"校准，不做高频搜索。

### 5.2 OTA / 本地生活：只有飞猪官方对个人开放

| 平台 | 个人开发者 | 结论 |
|---|---|---|
| **飞猪 FlyAI**（flyai.open.fliggy.com，2026-03 上线） | ✅ 条款明文「仅向年满 18 周岁的个人开发者开放」，免费 | 唯一官方面向个人 Agent 的国内 OTA：`search_poi`（景点/门票/一日游）、`search_hotels`、`search_flight`、火车；返回结构化 JSON + `jumpUrl` 直订链接；签推广者协议后**酒店/度假成交自动分佣**（交通类不分佣）。**工程约束**：CORS 白名单 + HMAC 签名，浏览器不可直连，需边缘代理 |
| 携程问道开放平台 | ✅ 个人携程账号申请 Token | 自然语言问答（酒店/机票/景点/行程），**返回 Markdown 文本不是结构化数据**，只能做问答层 |
| 携程联盟（u.ctrip.com） | ✅ 个人可入驻 | H5/小程序取链，酒店佣金约 2%-4%；OpenAPI 需企业 |
| 同程联盟（union.ly.com） | ✅ 个人站长 1 工作日审核 | refid 代理链接；官方公示佣金：门票 2%-4%、火车票 3-7 元/张 |
| **美团** | ❌ 官方原文「暂不提供个人开发者的对接服务」 | **无任何 POI/门店搜索 API**（接口仅操作商家自己门店）；部分业务 10 万保证金；联盟 CPS 个人只能手动取链；**无 MCP**（走与微信/元宝的 A2A，不对第三方开放） |
| 大众点评 | ❌ 无开放平台 | 评价内容从未开放；大众点评诉百度案（2016-2017）确立「抓取 + 实质性替代 = 不正当竞争」 |
| 马蜂窝 / 去哪儿 / 艺龙 | ❌ 纯企业 B2B | — |

### 5.3 对行记的接入决策

1. **步数引擎**：高德（境内）+ ORS（境外）双引擎——**v0.1 已实现**
2. **POI 校准**：v0.2 接高德 POI 搜索到采集箱（解析出的俗称地名 → 坐标），严格缓存
3. **景点/门票/酒店 + 变现**：v0.2 评估飞猪 FlyAI——同时解决数据与分佣，但要接受一个极薄的边缘代理（Cloudflare Worker 十行转发，持 Key 并补 CORS）
4. **轻变现**：POI 卡片挂携程联盟 / 同程联盟 refid 链接，零 API 成本
5. **美团**：写进 Non-goals；餐厅 POI 用高德代替
6. **MCP vs 直调**：确定性步骤（批量算路/距离）由代码直调高德 REST，LLM 只做"哪天去哪"的编排——一次编排 20-40 次 LLM 工具调用既慢又烧配额

## 6. 合规红线（写入代码与文档的硬约束）

1. 不做任何形式的小红书自动抓取（爬虫、第三方聚合 API 均不进入产品链路）
2. 攻略原文只在用户本机内存中处理，不留存、不上传服务器（产品本身零后端）
3. 解析结果必须经用户确认才入库（同时对准确性与版权负责）
4. 高德 / ORS / 模型 Key 均为用户自有 BYOK，不代持、不代充；地图个人免费配额条款为「学习研究用途」，产品正式商用前需注册公司主体走高德乘风计划 / 百度扶摇计划并购买技术服务许可
5. H5 手记中的照片均为用户自摄内容；攻略参考图由用户自行上传，仅供个人对比使用
6. 不对美团 / 大众点评 / 携程页面做任何爬虫式或浏览器自动化抓取（含 AI Agent 操控浏览器）；国内 OTA 数据只走官方面向个人开放的通道（飞猪 FlyAI、携程问道、各联盟 CPS 链接）
